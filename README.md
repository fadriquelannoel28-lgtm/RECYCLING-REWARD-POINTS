# EcoCoins - Automated Recycling Reward Points System (Python & Flask)

A Web-Based Automated Recycling Reward Points System for Barangay Residents built with Python (Flask) and Bootstrap 5.

## Pages & Routes

- `/` : Landing page with station overview and community impact
- `/how-it-works` : 5-step recycling explanation
- `/login` : Account login with password toggle
- `/register` : Resident registration with auto QR generation
- `/dashboard` : Resident dashboard with balance, monthly stats, and personal QR code
- `/ecopoints` : Points distribution and material progress bars
- `/history` : Recycling history with category filter
- `/rewards` : Community partner rewards catalog and instant redemption
- `/station-simulator` : Collection station terminal to scan QR and deposit recyclables
- `/admin` : Barangay administrator portal with dark green sidebar
- `/402` : Custom 402 connection/payment notice page
